# SingleClik

> High-performance, SEO-first React boilerplate — Vite 8, React 19, TypeScript 6, Tailwind v4.

A modular, production-grade React starter built around:

- ⚡ **Vite 8** + **React 19** with the **React Compiler** on
- 🧩 **Feature-based architecture** — every page lives in `src/features/<name>/`
- 🎨 **Tailwind CSS v4** with `@theme` design tokens (no JS config)
- 🧭 **react-router 7** with route-level code splitting (`React.lazy`)
- 🪪 **react-helmet-async** + a typed `<Seo />` component
- 🛰️ **@tanstack/react-query 5** with typed fetch wrapper
- 🌗 **next-themes** dark/light/system
- 🗺️ Build-time **sitemap.xml** generator
- 🚨 Top-level `<ErrorBoundary />` with graceful fallback
- ✅ CI workflow, editorconfig, oxlint, conventional commits

---

## 🚀 Quick start

```bash
nvm use                 # or: fnm use
npm install
cp .env.example .env.local
npm run dev             # http://localhost:5173
```

## 🔎 SEO

- Per-page metadata via `<Seo {...preset} />` — see `src/features/<page>/seo/`.
- Open Graph, Twitter, canonical, JSON-LD all wired.
- `public/sitemap.xml` regenerated by `scripts/generate-sitemap.mjs` on every build.
- `public/robots.txt` allows all and points at the sitemap.

## ⚡ Performance

- **Code-split routes** — every page is a separate chunk (`HomePage` ~5 kB, `AboutPage` ~2 kB).
- **Manual vendor chunks** — react, router, query, meta, theme, icons each get a stable hash.
- **Long cache headers** — hash-named assets + vendor splitting keep React cacheable across deploys.
- **Preconnect** to API origins in `index.html`.
- **System font stack** — zero web-font penalty.
- **React Compiler** — automatic memoization.
- **React Query** — `staleTime: 60s`, no refetch-on-focus.

## 🎨 Theming

Colors live in `src/index.css` using the Tailwind v4 pattern:

```css
@theme { --color-brand: #2563EB; }              /* raw token → bg-brand, text-brand */
@theme inline { --color-primary: var(--color-brand); }  /* alias → bg-primary */
@layer base { .dark { --color-bg: var(--color-ink); } }  /* dark mode flips raw tokens */
```

Add a new color once in `@theme`, use it everywhere via `bg-X` / `text-X`. Never hard-code hex.

## 🚢 Deployment

The build output (`dist/`) is a static bundle. Deploy anywhere:

- **Vercel** — `vercel deploy --prod`
- **Netlify** — `netlify deploy --prod --dir=dist`
- **Cloudflare Pages** — `wrangler pages deploy dist`
- **GitHub Pages** — push `dist/` to a `gh-pages` branch (set `base: './'` in `vite.config.ts` for sub-paths)
- **Any static host** — serve `dist/` with `Cache-Control: public, max-age=31536000, immutable` on `assets/*`
